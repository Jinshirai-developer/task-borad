ブラウザ体験版

まずは、ひとつ完了してみてください。

  1. 01

    タスクを動かす

    カードをDONEに移動。完了を取り消したときの変化も確認できます。

  2. 02

    チームに切り替える

    担当者・チェックリスト・お助け依頼など、チームの仕事を整理できます。

  3. 03

    相棒の成長を見る

    タスクの完了で経験値が増えます。相棒との触れ合いや着せ替えも試せます。

体験版はサンプルデータで動作します。変更は再読み込みでリセットされ、実際の招待・共有・決済は行いません。

使用技術と実装について

Web・バックエンド
HTML / CSS / JavaScript、ASP.NET Core 10、Entity Framework Core、PostgreSQL。認証、個人・チームの権限、更新競合の検出、タスク完了による報酬の整合性を実装しています。

Windows
C# / WPF / WebView2。Web版と画面を共通化し、起動・接続先設定・外部ブラウザでのログインに対応しています。

このページのブラウザ体験版は画面と操作の確認用です。バックエンドへの保存・実ユーザー同士の通信・Google認証は利用できません。Windows版は署名・専用インストーラー・自動更新に未対応です。
