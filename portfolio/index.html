ブラウザ体験版

まずは、ひとつ完了してみてください。

  1. 01

    タスクを動かす

    カードをDONEに移動。完了を取り消したときの変化も確認できます。

  2. 02

    チームに切り替える

    担当者・チェックリスト・お助け依頼など、チームの仕事を整理できます。

  3. 03

    相棒の成長を見る

    タスクの完了で経験値が増えます。相棒との触れ合いや着せ替えも試せます。

体験版はサンプルデータで動作します。変更は再読み込みでリセットされ、実際の招待・共有・決済は行いません。

Windows版 · 0.1.1

デスクトップでも、Task Board。

ZIPをすべて展開して、TaskBoard.Windows.exeを起動。
登録・ログイン画面が自動で開きます。URLの入力は不要です。

Windows x64向け · .NETランタイム同梱
Web版と同じアカウントを使えます。サーバーの稼働中に利用できます。
接続できないときも、同梱の体験版を利用できます。

使用技術と実装について

Web・バックエンド
HTML / CSS / JavaScript、ASP.NET Core 10、Entity Framework Core、PostgreSQL。認証、個人・チームの権限、更新競合の検出、タスク完了による報酬の整合性を実装しています。Web版のAPIとデータベースは開発者のMac上で動作し、HTTPSで中継しています。サーバーの稼働中に利用できます。

Windows
C# / WPF / WebView2。Web版と画面を共通化し、起動時の自動接続・外部ブラウザでのログインに対応しています。

登録せずに使う体験版はサンプルデータで動作し、変更を保存しません。Windows版は署名・専用インストーラー・自動更新に未対応です。
