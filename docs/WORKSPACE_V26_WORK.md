# 再読み込み後のチーム選択保持（2026-09-09 / v26.1）

以前はページ起動時に個人ワークスペースを選び直していた。同じタブで再読み込みした場合、直前に選んだチーム、または個人を開くよう修正した。ローカルの http://localhost:5097/ に反映済み。

## 挙動

- 認証済みのプロフィールIDごとに、選択したチームIDだけを `sessionStorage` へ保存する。同じタブ内の再読み込みが対象で、別端末や新しく開いたタブへの同期はしない。
- 起動時は所属チーム一覧で参加状況を確認してから復元し、その後にタスク一覧を取得する。個人タスクを一度取得してから共有に切り替える表示は行わない。
- 退出・削除済み、または不正な保存値なら保存値を消し、個人を開く。一時的にチーム一覧を取得できない場合は再試行案内を表示し、保存値は次回の再読み込みに残す。
- 個人への切り替え、チーム作成・参加後の移動、退出・削除後の移動も同じ保存処理を通る。
- アカウント間で選択を混ぜない。お試しデモは保存・復元の対象外とし、従来のリセット動作を維持する。
- ブラウザの保存領域が使えない場合も通常の切り替えは動作する。
- 読み込み中にワークスペースを明示的に選んだ場合や、フォーム入力・タスク操作を開始した場合は、遅れて返った結果で自動的に切り替えない。

テーマ・レイアウトは引き続きサーバーへ保存する。パスワード、Cookie、CSRFトークン、タスク本文は今回のブラウザ保存に含めない。DBスキーマとAPIの変更はない。
