# v23: SOSの宛先指定

2026-09-09。チームのSOSを全員向けまたは1人宛てで出せるようにした。

## 使い方・互換性

チームのタスク → メモ → 相談・SOS → SOSの宛先。候補は現在のチームメンバー（自分以外）。初期値はチーム全員。メインボードに設定欄は追加していない。

宛先は詳細と共有一覧に表示し、閲覧者が宛先なら「あなた」を付記。特定宛ての場合はその人だけが「見ます・手伝います」を押せる。APIも同じ制限を適用し、所有者であっても宛先を迂回して応答はできない。作者・所有者の解決／取り下げ権限は維持する。

内容はチーム内で共有される。DM・メール・プッシュ通知ではない。既存SOSは全員向けとして扱う。SOSを出した後の宛先変更は、取り下げて出し直す。タスク担当者・状態・経験値は変更しない。

JSONのWorkHelpにRecipientIdとRecipientUnavailableを追加。依頼DTOの既存RecipientIdを共用する。DBスキーマ変更はない。全員向けはnullとして送り、空文字によるモデルバインディングエラーを防ぐ。

宛先が退出・退会した未解決SOSは終了し、勝手に全員向けへ変更しない。退会時はIDを除去し「退出・退会済み」を表示する。解決履歴と削除タスクのUndoスナップショットも処理し、復元で宛先や未解決SOSを復活させない。
