# ログイン画面の刷新（2026-09-09 / v27）

小さなWindows風のログイン枠から、相棒とタスク管理の使い方が伝わる入口へ変更した。ローカルの http://localhost:5097/login.html に反映済み。

## 変更

- 明るい背景・落ち着いたグリーン・余白を使った2カラム構成。左に用途とボードの画面イメージ、右にログインフォームを配置。
- ボードのイメージはHTML/CSS、相棒は既存の透過ねこ画像を使用。実際のユーザー情報や架空の利用実績は掲載していない。
- ログインを主操作に、新規登録・登録不要デモ・パスワード再設定・確認メール再送の入口を整理。
- パスワードの表示／非表示を追加。登録への切り替えと送信開始時は非表示に戻し、処理中は切り替えを受け付けない。
- 新規登録時の見出しと説明、文書タイトルを連動。従来の入力条件、メール確認、規約同意、Cookie／CSRF処理を維持。
- `login.css` をログインとアカウント手続き画面で共有し、確認・再設定のフォームも同じ配色に統一。ボードの表示テーマは変更していない。
- 760px以下は1カラム。大きな説明用イラストを省略し、ログイン操作を優先。入力文字は16px、フォーカス表示と動きを抑える設定にも対応。
