# Windows 0.1.1 — 起動時の自動接続

## 変更内容

起動直後の接続先URL入力画面を削除し、`https://taskboard-8j6.pages.dev/` の登録・ログイン画面へ自動接続するようにした。ログイン済みの場合は既存のWeb側の認証処理でタスクボードへ進む。旧版の接続先設定は読み込まない。公開サーバー用のWebView2プロファイルとログイン情報は従来の保存先を引き継ぐ。

通信に失敗したときは「再試行」と「お試しモードを開く」を表示する。デモ利用中の「オンラインに戻る」も固定の公開サーバーへ接続する。Googleの認証は引き続き外部ブラウザーで行う。

## 確認範囲

Windowsの自動確認は、新規プロファイルでの登録フォーム表示と同梱デモの初期化まで。既存セッションの復帰、サーバー停止時の再試行、実Googleアカウントの承認操作は今回のWindows自動確認に含めていない。

旧版への自動更新はないため、利用者は新しいZIPをダウンロードして展開する。サーバーは引き続き運営者のMacで稼働する。コード署名・専用インストーラー・実データのオフライン編集は追加していない。
