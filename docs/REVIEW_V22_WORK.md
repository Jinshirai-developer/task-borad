# v22: 機能追加中心から日常操作の整理へ

2026-09-09。批判的レビューを受けた修正。既存のデータ・画像・テスト契約は削除せず、導線と報酬ルールを変更した。

## 実施したこと

- 表示・ペット選択をLv.1から利用可能にした。完了取消で種別・テーマ・レイアウトを戻さない。
- 装備は現在レベルではなく取得済み記録、成長姿は到達済みの記念記録で利用可否を判定。未獲得品の不正取得は拒否。旧Lv.6以上の取得品も保持する。過去にサーバーに保存された有効な成長姿については、その到達記録を補完する（不明な過去日時は作らない）。
- 休んだ日数による元気の減少・悲しい状態への遷移を廃止。経験値の取消・二重付与防止と操作による表情差分は維持。
- 新しくDoneになるタスクの経験値は担当者へ、未割り当ては操作した人へ。既存Doneの担当変更では過去の報酬を付け替えず、再開・Undoは元の受給者の記録を使う。
- 「メモ」「相談」「確認・引き継ぎ」を主導線へ。カードのメモボタン、相談中・受け渡し待ち・メモ件数の表示、ボード上部の一覧入口を追加。チーム管理とタグ登録は設定のまま。
- 作業メモは本文のみで保存可能。補足、試したこと、次の作業、リンクは任意。本人限定の続きメモは副操作に整理し、共有メモとの公開範囲を明記。
- 引き継ぎは「確認だけ／相手の受領時に担当変更」を明示。旧データは確認のみ。宛先以外の受領を拒否し、競合チェックも維持。
- 作品棚の新規作成を主導線から外した。保存済み記録と既存APIは削除せず、折りたたみから確認可能。
- 検索後・ページ分割前の状態別件数をAPIに追加。このページの件数と全体件数を区別し、他ページにあるタスクを「存在しない」と表示しない。
- 主要テーマをライト・ダーク・Windows風に整理。他テーマは折りたたみ、補助レイアウトは追加選択肢へ。6テーマ・5レイアウト自体は保存互換を維持。
- 設定内の課金入口を「決済テスト・契約管理」と明示。Stripe Sandbox・アカウント課金・無料3人制限と既存契約を維持。
- READMEを現行の使い方に整理。旧説明はREADME_BEFORE_V22.mdへ保管し、旧画面を現行のスクリーンショットとして扱わない。
