# チームProのプラン紹介・購入確認 v18

購入画面の見た目とカード入力の案内は、後続の [v19](RICH_PURCHASE_V19_WORK.md) で更新・ローカル反映済み。以下はv18の実装履歴。

## 実装と導線

既存のチーム管理ダイアログ内で専用ビューへ切り替える構成。メインボードに常設欄は追加せず、既存の.NET・静的フロントエンド・認証・Stripe Sandbox接続を維持した。別サイトへの移行・外部公開は行っていない。

「設定 → タグ・チーム → 選択中のチームを管理 → チームProのプランを見る → テスト決済へ進む → Stripe Checkout → 決済の確認」。カード入力・保存をアプリへ追加していない。

- 対象チーム名、参加人数、所有者／メンバーの区別、対象がこの1チームだけであることを表示。
- 無料0円・所有者込み3人と、Pro月額500円・プラン人数上限なしを比較。価格は既存APIの `monthlyYen` を使用し、ブラウザーから金額・価格IDは送らない。
- テスト専用・実請求なし・毎月更新、期間末解約、無料復帰時の既存メンバー／タスク／XP／ごほうび保持を説明。
- 規約・プライバシーポリシーを別タブで参照可能。テストカード案内は折りたたみ。本文・価格・チーム名はテキストノードで描画。
- 閲覧だけではCheckoutを作成しない。最終ボタンを所有者だけに表示し、未接続時は無効。既存の未完了Checkoutは同じ試行を再開し、契約中は重複購入ボタンを出さない。
- 結果は確認待ち・中断・支払い未完了・契約終了・有効Proを区別する。戻りURLを購入証明にせず、対象チームのGET／明示的な同期結果を使用。同期は既存APIで、URLから自動購入・自動解約を行わない。
- Pro時の「メンバーを招待する」は管理画面の招待ボタンへ移動するだけで、既存招待コードを自動再発行しない。
- 遅い応答は世代と対象チームで照合。チーム画面を閉じる・ワークスペース切替で無効化する。購入処理中は二重操作を防ぎ、通信エラーや不正な遷移先は購入ビュー内に表示する。
- キーボードのフォーカスは既存ダイアログ内に保持し、「戻る」で起点へ戻す。スマホでは比較を縦に並べ、操作ボタンを画面下に表示。classic／Windows風retro／darkに対応。

`?billing=plans&team=...` は所属済みチームのプラン表示専用。読み取り・画面遷移だけでCheckoutを作らず、使用後はパラメーターを除去する。登録不要の見本は `http://localhost:5097/index.html?demo=1&billing=plans&team=1`。見本のPro表示はシミュレーションと明記し、再読み込みでリセットされる。
