# v24: ポートフォリオレビュー1〜6への対応

2026-09-09。[レビュー](PORTFOLIO_MANAGER_REVIEW_2026-09-09.md)の1〜6を対象に修正。DBスキーマの変更はありません。

## 変更点

1. カードの固定高さを解除し、相談中・引き継ぎ待ち・担当・チェックリストを途中で切らずに表示。操作ボタンを内容の下に配置。
2. 新規作成・編集を開いた時の入力を記録。変更後の閉じる・Esc・背景クリックで破棄確認。ブラウザを離れる際は標準の未保存確認。保存成功後は確認を出さずに閉じる。自動下書き保存ではありません。
3. スマホでは相棒を小さく表示し、補足情報・タグを展開式に変更。上部に追加・検索・依頼を配置。空のメッセージと1ページだけのページ送りを省略。
4. 全ステータスのタイトル・説明検索、担当者（自分・未割当・メンバー）、期限（今日・今日まで・期限超過・未設定）、期限順を追加。クイック条件は組み合わせ可能。日付はJSTの暦日、期限条件は未完了のみ。期限順は未設定を末尾へ。APIで絞り込んでから件数集計・ページングする。
5. 各カードのステータス選択と完了ボタンを追加。既存の競合検出・報酬・15秒Undoを使用。失敗時は表示を現在の状態に戻し、再操作可能にする。
6. `GET /api/work-inbox` と「依頼」一覧を追加。全参加チームの自分宛て・チーム全員宛てを分け、正しいチーム・相談タブへ移動。30秒ごとに件数確認、非表示タブでは停止。通信エラーは0件扱いにせず、古い一覧を消して再試行を案内。

## 依頼の扱い

- SOSは未解決・応答者なし・宛先有効なもの。自分が送った依頼は含めない。
- 引き継ぎは自分宛ての受領待ち、自分が送った依頼への質問返却。
- 一覧を開いただけでは依頼を消さない。応答・受領・解決等で対象から外れる。既読管理、メール、プッシュ通知は今回の対象外。
- APIは毎回所属を確認。返すのは依頼・チーム・タスクの表示情報のみで、本人限定の続きメモを含めない。
- チーム切替前の所属再取得が失敗した場合は移動しない。件数の定期更新で閲覧中の項目を突然入れ替えず、更新ボタンへ案内する。
- 現状は小規模チーム向けに所属チームの作業記録JSONを走査する。大量データ向けには依頼テーブルとページングの追加が必要。
