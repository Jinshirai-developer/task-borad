## 本番基盤・移行・スモークテスト

- [ ] 鍵の永続領域・権限・保管時暗号化・全インスタンス共有を設定する

- [ ] 既存DBのバックアップと停止時間を確保してMigrationを適用する（新旧同時稼働不可）
- [ ] 旧Bearer再利用不可と既存ユーザーの追加設定を案内する
- [ ] health/readiness、429/503、DB容量、メール失敗・滞留を監視する
- [ ] 公開URLで登録・確認・ログイン・CRUD・報酬・復旧・ログアウト・退会を確認する
- [ ] 不正CSRF・期限切れ/再利用リンク・別ユーザーデータ操作が拒否されることを確認する
