# ペット＋ごほうびの一体型差分（90枚生成済み・透過処理待ち）

依頼: 装備単体ではなく、ペットが身につけた画像を全パターン生成する。

今回の範囲は **6種 × 5レベル × 3種類 = 90枚**。通常姿・通常表情のペットに、帽子、リボン、クッションのいずれか1点が付いた一枚絵です。成長段階・表情・複数装備の組み合わせまでの網羅ではありません。この区別は制作開始時にユーザーへ明示済みです。

## 保存先

- `frontend/assets/pet/drafts/outfits-v1/{species}/lv-{level}-{hat|bow|mat}.png`: 90枚の生成原本のコピー。全て1254×1254 PNG、合計約152 MiB。実透過ではありません。
- `frontend/previews/pet-outfits-v1/index.html`: 一覧の確認ページ。ファイルとして直接開けます。
- `manifest.json`: 90件の制作プロンプト・参照画像・予定パス。
- `results/{key}.json`: 完了した生成の実プロンプト・原本パス。結果側が最終記録です。
- `final-audit.json`: 全90枚の存在・重複なし・原本とのSHA-256一致・寸法・透明度の検査記録。
- `review.json`: 制作と表示確認の最終状態。各results内のstatusは生成直後の状態を記録したものです。

## 制作方法と現時点の制約

imagegenスキルの内蔵ツールを使用し、1差分につき1回ずつ生成。既存のペット本体を同一性の基準にし、装備の確認画像をデザイン参照に指定しています。種別ごとの顔・毛色・バンダナ・ポーズを維持し、頭や首、足元に自然に付いた状態を描く指示です。

生成ツールに実透過を依頼しましたが、最終検査では90枚ともRGB画像で、実透過は0枚でした。格子模様は画像に焼き込まれており、背景は未透過です。原本を透過素材とは表記しません。背景だけをPythonで透明化してよいか確認質問を送っていますが、この記録時点では未回答のため、今回の原本へのPython画像編集は行っていません。原本を残し、ペットや装備のRGBを描き変えずに背景のみのalphaを処理する方法について、ユーザーの返答を待っています。

今回は画像制作・保存・確認ページのみ。本アプリの表示コード、経験値、受取・装備の保存処理、DB、稼働コンテナは変更しません。生成画像をそのまま動かすとクッションも動くため、将来の組み込み時には背景固定や複数装備・表情との対応を別途設計する必要があります。
