# 画面キャプチャ

ゲームに組み込む素材ではなく、動作確認・ポートフォリオ説明用の画像です。全66枚を残したまま分類しました。

- `app/v2/` 〜 `app/v11/`：ボード・テーマ・タグ・チーム・設定の各変更時点。
- `pets/collection-v12/`、`pets/collection-v14/`：ペット設定・ごほうび・アルバムの画面。
- `pets/cat-v13/`、`pets/cat-v14/`：猫の本アプリへの組み込み確認。
- `pets/rewards-v14/`：6種類の使用中の装備見本。生成時のデザイン参照にも使用。
- `pets/outfits-v1/final/`：一体型90差分の最終一覧（1種15枚ずつ、6画像）。未透過・未反映であることを表示。
- `pets/outfits-v1/drafts/`：制作途中の一覧。履歴として保管。

READMEから使用している画像リンクも更新済みです。写っているデータは検証用で、招待コードやアカウントを実データとして利用しないでください。
