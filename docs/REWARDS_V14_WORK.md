# Lv.1〜5 ペット別ごほうび制作・実装（完了・反映済み）

最新依頼: 時間をかけてよいので、ごほうびをLv.5までに絞り、帽子・リボン・クッションの画像を生成し、ペットごとに似合うごほうびに分ける。

## 方針

- 6種 × 5レベル × 3種類 = 90個の独立した画像。imagegenスキルの内蔵ツールで1品ずつ生成。
- 帽子・リボン・クッションの3装備枠を維持。新素材は装備単体、ペットの耳/角/首/足元に合わせて種類・成長姿ごとの表示位置を調整。
- 現行の1レベルにつき3候補から1点を選ぶ方式を維持。種類変更で2点目を得られるようにはしない。受取記録は共有し、表示デザインがペット別に変わる。
- ペット自体のレベル・XP・成長姿の解放上限は変えない。新規ごほうびだけをLv.1〜5に制限。
- Lv.6〜20の受取済みは旧コレクションとして保持し、再装備・同じ申請の再送・レベル低下による解除を維持。新規のLv.6以上受取はサーバーでも拒否。
- 元のPNGを保管し、過去の猫素材で明示的に許可されたPythonによる背景のみの透明化を再利用。今回送信した任意の再確認質問には返答なし。RGBを変えず、外側に連結した背景のalphaだけを除去し、90品・6アトラスの検査記録を保存した。
- 90素材と表示・保存・回帰検証を完了後、本アプリ（localhost:5097）を `task-board:rewards-v14` に更新済み。

`rewards-v14-generation.json` は初期制作計画。最終の生成結果・プロンプト・原本パスは `reward-generation-v14/{species}_{level}_{kind}.json`、実際の表示名は `Services/PetRewardArtCatalog.cs` が正。耳や角が素材側に描かれた11点の帽子は再生成して差し替えた。
