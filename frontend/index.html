        アカウントの削除

        個人のタスク・ペットの育成データを削除してチームから退出します。共有タスクはチームに残ります。元に戻せません。所有するチームがある場合は、先に所有権を譲るかチームを削除してください。

        招待コードをメンバーに送る

        相手はログイン後、「設定 → タグ・チーム → 招待コードで参加」に入力してください。

        コードはこの画面を閉じると非表示になります。信頼できる相手だけに送ってください。再発行は「設定 → タグ・チーム → 選択中のチームを管理」からできます。

        まずはチーム名を決めましょう

        名前を入力するだけで作成できます。次の画面で招待コードをコピーして、メンバーを招待しましょう。

        招待コードをお持ちの方

        チームを作った人から届いたコードを入力してください。参加すると、そのチームのタスクを閲覧・編集できます。

          コードを知っている人が参加できます。信頼できる相手だけに渡してください。再発行すると前のコードは無効になります。

          チームの削除

          全メンバーのチーム参加情報と、このチームのすべてのタスクを削除します。個人のタスクは削除されません。元に戻せません。
